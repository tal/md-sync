# `--cwd` global flag

- Added `--cwd <path>` (all commands): resolved against the real cwd, must be a directory (else exit 2), then `process.chdir` + used as `cwd` for relative `--dir`/`--config`/`--ssh-key`/`flush --path` and synced-folder discovery.
- Why `chdir` and not only passing `cwd`: `src/service.ts` resolves `install-service` path flags with `process.cwd()` directly, so only a real chdir keeps it consistent.
- Docs: ARCHITECTURE §13.1 table + §20 D57, README, `--help` text. Tests in `test/unit/cli.test.ts`.
