# Rename the executable to md-sync

The package bin is now `md-sync`, and local builds produce `dist/md-sync`. Release assets use `md-sync-<platform>`. CLI help, version output, stderr prefixes and command hints use the same spelling, along with installation instructions, hooks and CI binary smoke checks. No `mdsync` executable alias is provided.

This is a command rename, not an npm publication or a state migration. Existing `.config/mdsync.json`, XDG `mdsync/` directories, `MDSYNC_*` variables, service identifiers, authors, internal refs and notification workflow names remain stable. Update callers of `mdsync`, and reinstall services after replacing a compiled executable so their recorded executable path points to `md-sync`.
